SSTV Console for Windows

1. Unzip this folder somewhere you can write to, e.g. Documents or your Desktop
   (not Program Files: the app updates itself in place).
2. Run SSTV-Console.exe. Windows shows "Windows protected your PC". That's because the
   program isn't signed with a paid certificate, not because anything was found wrong.
   Click "More info", then "Run anyway". (No "Run anyway"? Right-click the .zip you
   downloaded > Properties > tick Unblock > OK, and unzip again.)
3. That's the last time: SSTV Console checks for new versions on its own and offers
   "Install and restart". About > Check for updates checks right away.

The window is Microsoft Edge in app mode (no tabs or address bar). Edge comes with
Windows 10 and 11.

Full steps with explanations, how to verify your download, and the source code:
https://github.com/Jnubbz/sstv-console/blob/main/docs/INSTALL.md

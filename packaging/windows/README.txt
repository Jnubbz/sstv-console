SSTV Console for Windows

1. Unzip this folder somewhere you can write to, e.g. Documents or your Desktop
   (not Program Files: the app updates itself in place).
2. Run SSTV-Console.exe. If SmartScreen warns, choose More info > Run anyway.
3. That's the last time you install it by hand: SSTV Console checks for new versions on
   its own and offers "Install and restart". About > Check for updates checks right away.

The window is Microsoft Edge in app mode (no tabs or address bar). Edge comes with
Windows 10 and 11.
